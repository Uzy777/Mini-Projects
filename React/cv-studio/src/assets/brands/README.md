# Brand SVG assets

Unmodified monochrome LinkedIn, GitHub, GitLab and YouTube SVGs from
[Simple Icons 11.15.0](https://github.com/simple-icons/simple-icons/tree/11.15.0/icons).
The accompanying CC0 license is in `LICENSE.txt`. Brand names and marks belong to their respective owners.

Assets are bundled locally. The editor inverts the monochrome images in dark mode for contrast.
